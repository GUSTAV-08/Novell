# Хроники Фрейдра — Immersive Novel Experience

Структура и модули не менялись (ТЗ v2.0, п.13) — это те же файлы, что и раньше,
доработанные на месте.

```
index.html
css/  style.css, animations.css, responsive.css
js/   main.js, reader.js, world.js, characters.js, gallery.js, encyclopedia.js
assets/
  images/mountains.png   — фон сцены (не менять, не заменять)
  images/characters/     — портреты персонажей
  images/gallery/        — изображения галереи
  map/index.html         — сюда кладётся экспорт карты из Azgaar's Fantasy Map Generator
  audio/*.mp3             — звук (необязательно, сайт работает и без файлов)
```

## Что изменилось по ТЗ v2.0

1. **Фон** — без изменений: `mountains.png` остаётся единственным художественным
   фоном, поверх него по-прежнему только туман/свет/аврора/снег через CSS.

2. **Книга** — полностью переработана как древний фолиант, без "CSS-блока":
   слоистая кожа с потёртостями и царапинами (`.cover-leather/.cover-wear/.cover-scratches`),
   металлические уголки с заклёпками (`.cover-corner`), объёмный корешок (`.book-spine`),
   неровный пожелтевший торец страниц с ощущением толщины (`.page-block`).

3. **Открытие книги** — теперь это открытие, а не исчезновение: эмблема и руны
   разгораются → свет проступает по кромке крышки → крышка откидывается по
   верхней грани (`.book-cover`, hinge на `rotateX`) → видны страницы → лёгкая
   золотая пыль → плавный переход в меню. Никакого "магического салюта" —
   вспышка при клике теперь маленькая и тонкая (`.book-click-glow`).

4. **Эффект при нажатии** — сведён к минимуму: короткий мягкий импульс света
   у обложки, без резких вспышек и частиц.

5. **Главное меню** — та же концепция (раскрытый фолиант), добавлены лёгкий
   свет по верхнему краю страниц и тень в месте переплёта для объёма.

6. **Читальня** — теперь двухшаговая: раздел "Читать" открывает только список
   глав ("Том I" → "Глава 1, 2, 3…"). Сама страница с текстом, настройки шрифта
   и перелистывание появляются только после выбора главы (`js/reader.js`).

7. **Карта мира** — собственная SVG-карта убрана. Вместо неё — `<iframe>`,
   в который подключается готовый экспорт карты из **Azgaar's Fantasy Map
   Generator**. Положи свой экспортированный `index.html` (карта уже со своей
   интерактивностью, зумом и панорамированием) в `assets/map/index.html` —
   заработает без правок кода. Если файла нет, вместо карты вежливо
   показывается инструкция, сайт не ломается.

8. **Персонажи** — расширенный набор полей (имя, возраст, рост, раса,
   государство, фракция, статус, ранг, оружие, магия, особенности, биография,
   интересные факты, связанные персонажи, история). Пустые поля просто не
   отображаются — ничего заполнять "для галочки" не нужно.

9. **Энциклопедия** — 10 категорий (Расы, Государства, Магия, Артефакты,
   Монстры, Религия, История, События, Флора, Фауна) + живой поиск по всем
   статьям сразу (`#encyc-search`).

10. **Галерея** — добавлены стрелки вперёд/назад в лайтбоксе (клавиатура:
    ← → и Esc), подписи и плавное появление сохранены, ленивая загрузка на месте.

11. **Анимации** — везде `cubic-bezier`/`ease-in-out` вместо линейных, дракон и
    туман двигаются медленнее и мягче, переворот страницы — с инерцией.

12. **Производительность** — количество частиц пыли уменьшено (6–16 вместо
    10–28), лишний DOM не создаётся, все анимации — только `transform`/`opacity`
    (GPU-friendly), тяжёлые фильтры не используются.

## Как наполнить контентом

Всё содержимое — в начале соответствующих `.js`-файлов:

- Главы романа → `js/reader.js`, массив `CHAPTERS`
- Персонажи → `js/characters.js`, массив `CHARACTERS`
- Изображения галереи → `js/gallery.js`, массив `GALLERY_ITEMS`
- Статьи энциклопедии → `js/encyclopedia.js`, объект `ENCYCLOPEDIA`
- Карта мира → положить экспорт Azgaar FMG в `assets/map/index.html`

## Чего нет в комплекте

- Экспорт карты Azgaar (`assets/map/index.html`) — без него раздел "Мир"
  покажет инструкцию вместо карты.
- Реальные mp3 для звука — без них сайт просто работает молча.
- Портреты персонажей и изображения галереи.
